# Пять концепций для кафе

Откройте `index.html` в браузере. В папках `utro`, `forma`, `muka`, `noir`, `sol` находятся отдельные сайты. Общие стили и анимации — в `style.css` и `script.js`.

Это демонстрационные проекты: названия, меню, цены и адреса приведены для примера. Формы заказа и бронирования, оплата и настоящие контакты не подключены. Фотографии загружаются с Unsplash, шрифты — с Google Fonts; для их отображения нужно интернет-соединение. Перед коммерческим использованием проверьте права на фотографии, названия и товарные знаки, замените примеры реальными данными.

Для GitHub Pages загрузите содержимое этой папки в корень репозитория и включите Pages из ветки с этими файлами.
